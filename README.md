# practice

Small Go exercises split into `Day1/` and `Day2/`, each with three files
covering basic data-structure/algorithm practice (e.g. a `Matrix` type with
JSON tags in `Day1/file1.go`).

## Status

Written in July 2022 as short-lived practice; not maintained.

## Running it

Each file is a standalone `package main`:

```
go run Day1/file1.go
```
